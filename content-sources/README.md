# İçerik Kaynakları

Bu klasör, web sitesindeki bilimsel makalelerin kullanıcı tarafından sağlanan kaynak belgelerini saklar. Dosyalar `public/` altında değildir; canlı sitede doğrudan yayınlanmaz.

Web içerikleri `lib/articles.ts` içinde sadeleştirilmiş ve web okumasına uygun hale getirilmiştir. Kaynak belgelerde eksik olan bibliyografik bilgi tahmin edilerek tamamlanmamıştır.
